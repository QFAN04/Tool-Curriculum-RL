# 从 Qwen3-4B-Base 到工具调用模型

LoRA SFT、GRPO、SDPO 与失败驱动课程的最终研究报告

2026-11-15 · D1–D12 实验收官

## 摘要

这个项目从一个很具体的问题出发：一个 4B 基座学会按 schema 调工具以后，继续做强化学习、给它更详细的错误反馈，或让它按自己的失败出题，哪一种还能帮它答对新题？

最大的变化来自 SFT。Qwen3-4B-Base 加三个示例在原分布未见工具族上只做对拒答题，严格分为 276/1842（14.98%）。修复特殊 token 后训练出的 E0 达到 1736/1842（94.25%）。再往上走，原分布封存集的改善多是几道题，主要出现在双调用与多次采样分层。真正拉开方法差距的是换算留出集。相同请求一旦需要先算参数，E0 从直给版的 392/392 掉到 241/392。定向 SFT 和二值 GRPO 分别救回 110 和 95 道换算题。失败驱动课程 C-F 在相同生成次数和训练步数下比均匀生成 C-U 多答对 32 道，收益集中在单价、数量和折扣换算。课程的这项收益在通用封存集上没有同步出现。

## 2. RQ1 · Base 到 LoRA SFT，模型先学会了什么

### 先让模型能稳定交付一次调用

D1 证明单卡 PRO 6000 可以跑 LoRA GRPO 和 SDPO。直接用未 SFT 的 4B Base 做 SDPO 冒烟时，第一步耗时 934 秒，平均奖励 0.016，37% 的输出顶到 1024 token 上限。D3 首版 SFT 的调用严格分依然为零，截断率为 100%。排查发现，Base 的输入与输出嵌入共享，6 个与对话边界和工具协议相关的特殊 token 初始向量余弦相似度为 1.000。冻结这些行做 LoRA 时，输出反复出现乱码。去掉乱码外壳后仍能匹配 874/960 道 dev 调用题，说明首版已学到不少调用内容，模型无法把它可靠地包成可解析的回复。重新初始化并训练这 6 行后，v2 的 dev 截断率降到 0，完整 dev 严格分为 93.27%。随后按标准调用键重新划分 SFT/RL，保留原 dev/test，得到本报告使用的 E0。[D1 冒烟](experiment_cards/d1_smoke.md) · [D3 修复记录](reviews/2026-11-13_d3_astra.md) · [D3 SFT](experiment_cards/d3_sft_probe.md) · [标准调用键去重](experiment_cards/d3_gold_disjoint.md)

为什么后续模型的未见族总分大多挤在 94% 附近？0 次和 1 次调用占 1582/1842（85.88%）。E0 在这两层已做对 1510/1582（95.45%），其中拒答 276/276、单调用 1234/1306（94.49%）。真正剩下明显空间的是 3+ 次调用（89/110），这一层对总分的权重很小。对称默认值等价还把 E0 的未见族分数再救回 8 题至 1744/1842。开发集曾有大量显式空字符串默认值分歧，D12 的 8 题是封存集上实际测到的敏感度。

### `<think>` 空前缀是训练协议的一部分

D3 的 `enable_thinking=False` 把空的 `<think>…</think>` 放在输入前缀里，前缀标签由 `-100` 屏蔽。SFT 监督的是这个已闭合前缀之后的调用和结束符。D9 阶段 1 改用思考模式，要求模型自己输出可闭合的思考段。E0 和 X2 各 20 题均为 0/20 非空并闭合、0/20 工具调用、0/20 截断，实际输出是短文本。用 120 条带前置规划或拒答的样本预热 12 步后，E0 复测仍为 0/20，12 条输出与预热前逐字相同。这个干预验证了现有 checkpoint 依赖训练时的输出协议，支持闭合标签及其位置是调用起始线索的解释。切换同时改变了提示前缀和生成要求，实验未单独估计闭合 token 的因果作用。D9、D10 正式方法对照统一回到直接作答模式。[D9 阶段 1 归档说明](experiment_cards/d9_thinking_conversion.md#43482-实测验收)

## 3. RQ2 · SFT、二值 GRPO 和分级 GRPO 各自在哪儿有效

原分布上，去掉 SFT/RL 之间完全重复的标准调用后，RL 全池的混合组仍只有 240/2318（10.35%），单调用混合率 7.07%，3+ 调用则为 50.54%。靶向选出 581 题，用新采样复测后有 219/581 混合（37.69%）。D4 的 E1 在反复出现的训练题上从 83.74% 涨到 87.43%（首末各十步），同训练器的 dev_unseen 却由 482/541 到 481/541。统一独立 greedy 下，E0 / E0+ / E1 为 483 / 478 / 484 道。D8 的 X2 将同池严格 pass@1 从 85.76% 提到 87.59%，未见族多调用 dev 为 32/70，E1 为 33/70。题池上的进步没有按同样幅度传到新工具。[D3 靶向池](experiment_cards/d3_p0_targeted.md) · [D4 GRPO](experiment_cards/d4_grpo_targeted.md) · [D5 继续 SFT](experiment_cards/d5_e0plus_targeted.md) · [D8 X2](experiment_cards/d7_curriculum_bfcl.md#x2-补评完成c2-已接续)

但有差异的奖励并不都在强化最终正确。三次调用名称及格式都对时，完整参数命中 1、2、3 次分别给 0.60、0.80、1.00。在单价题上，重复调对工具、答对另一项换算，就能在单价仍错时取得 0.80。这个奖励会给大量部分正确轨迹正向区分，题目从部分正确走到完全正确时的相对排序也随同组其他输出而变。GRPO 会按组标准化，原始分差缩小本身不能推出梯度范数变小。实际结果是，分级比二值少对 41 道换算题，其中 38 道净差来自含 `rate_total` 的题。结果支持“局部刷分”作为解释：获得较高训练奖励的途径，未必要求把精确算术做完。现有记录没有直接测量单个参数上的梯度，也未单独识别部分给分与默认值归一化各自的影响。[D9 训练与结果](experiment_cards/d9_thinking_conversion.md) · [分级奖励实现](../src/tcrl/verl_reward_graded.py)

### SFT 的域内收益与二值 GRPO 的外部表现

Targeted SFT 在合成换算上最高，D12 全量从 E0 的 2881 降到 2877，seen 未见参数组合从 687/715 降到 684/715。二值 GRPO 在 D9 BFCL 得到自训组最高的 1072/1240，比同轮 E0 高 16 道。对外部四类调用和拒答并列看，二值 GRPO 分项为 358 / 185 / 179 / 168 / 182，当轮 E0 为 354 / 184 / 172 / 165 / 181。由历史多模型共同失败例冻结的 78 道调用诊断题，二值 GRPO 救回 8 道，Targeted SFT 为 6 道。

D12 全量严格 greedy 中，D9 Binary GRPO 以 2890/3018（95.76%）居 20 组首位，比 Targeted SFT 高 13 道（未校正 p=0.01255，Holm p=0.76551）。Seen 未见组合上为 691/715 对 684/715（未校正 p=0.04230，Holm p=1.000）。452 道拒答全部正确。未见工具族比 E0 多 5 道，净增都在双调用（137→142/150），总差 +0.27 pp，95% CI [−0.26, +1.23] pp。这个结果给二值 GRPO 一个跨评测表现稳定的候选位置。校正后的比较仍不足以确认它在通用工具调用上系统性优于 SFT。[D9 BFCL 分项](experiment_cards/d9_thinking_conversion.md#三臂训练与四臂终评43482) · [D12 主表与统计](experiment_cards/d12_final.md#34960-实测验收)

## 4. RQ3 · SDPO 的反馈有没有送到需要纠错的轨迹上

D6 从 E0 出发比较 E1、E2a、E2b 和 E2b-gold-only。E1 用二值 GRPO。E2a 只把校验错误给教师，关闭成功示范。E2b 允许含标准答案的反馈，也允许同组成功轨迹作示范。**正式归档里 E2b 的 `success_reward_threshold` 为 0.5**，对 {0,1} 序列奖励的成功判定与阈值 1.0 相同。E2a 和 E2b-gold-only 的阈值为 2.0，所以二值奖励下没有轨迹能作成功示范。这是示范资格门槛，日志中的反馈使用率衡量的是环境反馈实际进入教师提示的比例。

E2b 有两条教师提示路径，优先使用同组成功示范。复算发现 6527/7680 条训练轨迹（84.99%）本身已答对且同组还有成功轨迹。这样安排让标准答案反馈在日志里出现得少。固定 E0 和实际前缀，只看 35 道能定位错误 token 的标量参数题，现行无答案反馈有 10/35 同时压低错 token、抬高正确 token，只指出字段为 12/35，复述原错答加字段为 0/35，现行含答案且不复述错答为 35/35。这给出了教师看到答案后的纠错证据，也说明仅仅补充更多提示文字可能适得其反。

把 E2b 的阈值改为 2.0 后，环境反馈覆盖从 2.81% 到 13.85%。BFCL 从 1050 到 1056，D12 未见族双调用多 5 道、全量双调用多 6 道，严格和等价 pass@8 分别以 1783/1842（96.80%）和 1786/1842（96.96%）并列第一。也要看其余分层：未见族 greedy 总分为 1736/1842，与 E0 同分，原 dev_unseen 比 E2b 少 2 道。双调用层对 E2b 的未校正 p 在全量为 0.06960，在未见族为 0.17129，Holm p 均为 1.000。结论是关闭示范能把更多含答案的反馈送进教师，观察到的收益集中在部分题型和多次采样。现有对照无法把收益进一步拆成移除示范和增加答案反馈覆盖各自的贡献。[D6 反馈与教师诊断](experiment_cards/d6_sdpo_targeted.md) · [D12 分层结果](experiment_cards/d12_final.md)

## 5. RQ4 · 按失败自生成的课程，何时比均匀生成更有用

### D10 · 两边都用混合题，区别在练什么

C-F 相对 C-U 是 32 胜 0 负、+8.16 pp（Holm p=4.66e-10），四个未见域分别多对 7、10、10、5 道。对 C-S 多 87 道（Holm p=2.58e-26）。C-F 的合成留出格式错误率由当轮 E0 的 6.51% 降到 0%。两边都挑得满 360 道混合题。C-U 入训有 128 道直给题，其中 95 道只是落在 6–7/8，说明按混合筛选时，简单题也会因温度采样失误占到名额。C-F 的入训题全是隐式换算，1–3/8 的有 152 道，C-U 为 63 道（2.41 倍）。净增 32 道里有 26 道含单价总额。

折扣题也让课程边界变得很清楚。无折扣题上，C-F 做对 54/76，接近 D9 Targeted SFT 的 56/76。含 10% 折扣时，两者为 13/36 和 23/36。C-F 的 184 道合格折扣候选有 168 道（91.3%）在 E0 下为 0/8，被筛选排除，最终只留 11 道入训。这个结果和折扣收益较小相符。带通可以把课程引到模型有机会答对的地方，也会过滤掉生成标签可验但起点模型尚不会的题。与 D9 横向对标，C-F 的 337/392 接近二值 GRPO 的 336/392，逐题 6 胜 5 负。相对各自同轮 E0，C-F 的净增 97 道相当于 D9 Targeted SFT 净增 110 道的 88.2%。[D10 归档与复核](experiment_cards/d10_curriculum.md#d9d10-归档逐题复核)

### D7/D8 与 D12 · 多调用收益和拒答代价同时存在

原分布的生成对照已经显示 C-F 更擅长找到可练的难题。D7 两臂各冻结 300 道调用训练题，C-F 中 158 道是混合题，C-U 为 23 道。原版 C-F 纯调用续训后，原未见族 dev 拒答由 E0 的 81/81 降到 76/81，BFCL irrelevance 由 181/240 降到 143/240。D8 保留每臂的调用样本，加入 53 道拒答（约 15%），同时将学习率由 1e-4 降至 2e-5、步数由 30 降至 20。修正 C-F 回到 dev 拒答 81/81，BFCL irrelevance 178/240。封存集的未见族拒答同样从 D7 C-F 的 258/276 回到 D8 C-F 的 276/276。拒答回放让模型续训时仍练习何时不调用工具，这与各评测上的恢复一致。回放和训练强度一起变动，恢复幅度归于整套修正。D7 两臂共同非种子层的混合率为 14.02% / 16.98%，都低于 20% 门槛，因此停在配对 GRPO 之前。[D7 正式结果和 D8 回放](experiment_cards/d7_curriculum_bfcl.md)

D8 C-F 在全量双调用比 E0 多 7 道（未校正 p=0.01580），比同更新预算的 C-U、近似等 GPU 时的 C-S+ 各多 5 道（分别 p=0.03475 和 0.03325），三项 Holm p 均为 1.000。C-S+ 是静态臂额外跑 8 步以折算生成和筛选的 GPU 时间。D8 C-F 在 3+ 的严格 pass@8 上比表中的四个基线都多救回 3 道，同时以 96.80% / 96.96% 并列未见族严格和等价 pass@8 最高。D7 C-F 在 3+ 严格 pass@8 达全场最高 119/133（89.47%），未见族为 96/110，同时单次拒答和总分回退。这样的结果解释了为什么同一个课程可以提升困难题的可采样性，却降低日常使用的一次作答成绩。

### 再生成一轮，题有没有变好

D8 的 C2 只做生成与交叉评分。两轮各尝试 200 次。C1 有 163 道 grounded 候选，C2 有 161 道，臂内去重后 156 道。用两份 checkpoint 分别给两轮题打分，可以看到涨分来自题的变化还是答题模型的变化。

| 题池与答题模型 | 0/8、混合、8/8 | 混合率 | pass@1 | pass@8 |
|---|---:|---:|---:|---:|
| C1 / E0 | 26 / 52 / 85 | 31.90% | 70.71% | 84.05% |
| C1 / 修正 C-F | 24 / 55 / 84 | 33.74% | 71.63% | 85.28% |

固定 E0，第二轮题更容易采中。在同一批 C2 题上，换用修正 C-F 后通过率几乎持平。两轮总体覆盖的低频族均为 18，组合熵 5.896→5.906 bit。C2 有 68/156 与 C1 近重复。C1 的 C-F 抽查为 30/60 通过（18 拒绝、12 不确定），C2 为 49/100 通过（18 拒绝、33 不确定），分层抽样配比不同。两轮证据显示覆盖大体持平，候选难度有所变化，语义质量提升未建立。C2 没有训练第二轮模型，因此这个诊断回答的是出题动力学，第二轮的封存迁移没有测量。[C2 四格诊断与抽查](experiment_cards/d7_curriculum_bfcl.md#c2-短程诊断验收17346)

## 6. 结论的边界与复核入口

- 本项目最扎实的结果是：LoRA SFT 把基座变成了可用的工具调用模型；当评测要求先推导参数时，定向 SFT、二值 GRPO 和失败驱动课程都能提升未见工具域表现。分级奖励和 SDPO 分别提供了额外组内差异及可用纠错反馈，但增加信号覆盖本身没有保证通用封存收益。
- 原分布的工具调用是单轮内的调用集合，3+ 次表示组合调用数。项目没有执行真实工具或评估跨轮的工具结果依赖。BFCL 只覆盖冻结的 Python 单轮切片。合成任务也只有四个未见域，D10 使用已看过 D9 成绩的 392 对题作课程选择，最终候选的原分布成绩由独立 D12 封存集给出。
- D12 的区间量化当前 checkpoint 在工具族上的题目波动。大部分设置只有一个训练种子，D9 的 E0 与 D10 的同配置复评也有小幅差异（241 与 240 道换算题）。跨实验比分采用各自同轮 E0 计算增益，分层的未校正 p 值保留为诊断线索。
