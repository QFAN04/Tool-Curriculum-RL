# D6 · 双 PRO 6000 部署短测

- 单机两张 PRO 6000，各 97887 MiB。AutoDL 拓扑为同 NUMA 节点的 NODE 路径。两卡合计 ¥16.72/h，预计整轮 20–35 分钟，约 ¥5.57–9.75。
- 使用 D4 的去重版 E0、581 题、全局 32 题 × G=8、temperature=1.0，TP=1。先跑 GRPO 5 步，再跑 E2a 5 步。短测关闭验证与 checkpoint。
- GRPO 与 D4 单卡训练阶段比较第 3–5 步的吞吐、生成、logprob 和更新用时。单卡 D4 有 dev 验证和保存，整轮时间不直接比较。记录每卡峰值和每千条 rollout 成本。
- E2a 检查两卡显存余量、完成步数、反馈使用比例与成功示范为零。D3 的单卡含答案 SDPO 只作工程参考。
- 后台监视只投递完成或异常通知，由主控拉回日志并验收后关机。短测结果用于决定 E2a/E2b 正式配置。

耗时取各 run 第 3–5 步，显存取整个 run 的采样峰值。GRPO 双卡吞吐为单卡 1.07 倍，稳态千条轨迹费用从 ¥0.66 到 ¥1.23。D3 单卡含答案 SDPO 的 86.87 秒/步、97246 MiB 仅供工程参考，题池与反馈配置不同。

双卡 E2a 五步均无空目标批次，错误反馈实际使用率为 8.20%–16.80%，成功组和成功样本指标均为 0。逐条核对 1280 条 rollout，159 条带反馈，均未出现标准答案的 `expected:` 字段。两卡各有 6721 MiB 采样峰值余量。

两组退出码均为 0，归档 `runs/d6-dual-43482.tar.gz`，后台通知成功触发本聊天，关机命令返回 0。
