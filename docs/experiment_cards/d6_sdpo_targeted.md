D5 的退步主要是参数不匹配。E2a 对这类错误能指出参数不匹配，E2b 可以额外看到标准调用。主指标为同一独立 greedy 评测下 dev_unseen 的严格准确率。逐题报告参数错误修复和新增错误，同时记录实际反馈使用率、采样耗时和峰值显存。

D3 的含答案 SDPO 稳态约 87 秒/步，峰值距离单卡容量仅 641 MiB。每臂训练暂估 45–65 分钟，含启动、验证和回收整轮约 60–85 分钟，按 ¥8.36/h 约 ¥8.36–11.84。先用短程实测检查显存和反馈指标，再确认整轮预算。两臂合计费用可能超过 ¥20。

## 零 GPU 误差复盘

- E0 的 58 个 dev_unseen 严格错误中，48 个属于参数匹配，6 个多调、2 个漏调、2 个选错工具。36 题漏的是同一个可选参数 `weekly_id`，schema 默认值为 `""`。dev_unseen 有 52 题的 gold 显式传入该空字符串，去重版 SFT/RL 中均无该参数。
- 只在开发集诊断中，将这个工具调用省略 `weekly_id` 与显式传入 `""` 当作同一种写法，重算完整调用多重集，E0/E0+/E1/E2a/E2b 分别救回 35/44/36/37/34 题。原严格分数、训练奖励及封存测试保留原口径。该规则由 dev 错误导出，仅用于分析评分敏感度。
- E2b 的成功示范规则只排除当前轨迹自身。同组还有别的成功轨迹时，已经答对的轨迹也可获得示范。逐组复算，7680 条训练轨迹中有 6527 条已答对且同组另有成功轨迹（84.99%）。这是按轨迹计的示范资格，损失的有效 token 权重未测。
- 优先用冻结 E0 在训练池参数错题上比较原始提示、现有无答案反馈、标准答案反馈，复用教师模板并固定成功示范关闭。先确认反馈能否让教师纠错，再决定修改反馈内容还是尝试仅蒸馏失败轨迹。延长原配置暂缓。
## Argon 复核后的决策

- 旧 GeekNews 单向诊断作废。对预测与标准答案对称移除该可选默认参数后，五组未见族答对数为 523 / 523 / 524 / 522 / 523。对称移除所有 schema 声明的可选默认值后为 526 / 526 / 526 / 525 / 526。严格分数继续作为主指标。将 schema-default 等价作为补充指标，在查看封存结果前冻结实现与测试；只比对同一工具、同类型的显式默认值，保留必填项和非默认值。JSON Schema 默认值属于元数据，这项指标描述评分敏感度。
- 优先做冻结 E0 的 teacher-forcing 诊断，先覆盖约 100 条训练池内能定位参数值错误、且错误/正确 token 共用实际生成前缀的轨迹。比较原始学生提示、现有反馈、附实际错答及错误字段名的无答案反馈、再加标准答案。关闭同组示范，复用上游教师模板与截断规则；报告错误 token 与正确 token 的概率变化，以及训练实际使用的 student top-k 支持集上的蒸馏差异。参数顺序、空白等表面分叉不作语义错误位置。若样本不足，按实际有效样本数报告。
- 正向信号出现时优先只改 E2a 的反馈内容，保留当前成功示范关闭与训练掩码。若要精确隔离字段定位的贡献，加一个仅附错答的推理对照。暂不把失败轨迹掩码与反馈改动捆绑；字符占比和梯度范数无法确定实际稀释倍数。训练日志的解码保留了工具调用标签，暂无标签剥离证据。
### 冻结教师实测

从定向池 E0 的采样结果筛得 35 道可对齐的单调用、单标量参数值错误。固定模型与学生前缀。当前反馈、具体无答案反馈、具体反馈加标准答案三组的平均（错误 token、正确 token）对数概率变化分别为 (+0.24, −0.02)、(+2.46, −1.83)、(−3.07, +0.45)。同时压低错 token 且抬高正确 token 分别为 10/35、0/35、30/35。正确 token 全部进入学生 top-100。结果见 `runs/d6_teacher_token_probe/`。

具体无答案反馈包含原错答和参数名，其表现不支持进入短训。后续若开卡，优先在同一批样本上试只指出参数名、移除原错值的反馈，以区分错误值复述与字段定位。诊断只覆盖可对齐的标量值错误。
