# D6 · SDPO 短程对照

先跑 E2a，再用同一套配置跑 E2b。均从去重版 E0 出发，复用 581 题、全局 batch 32、G=8、30 步和 D4 的评测间隔。E2a 使用 `TCRL_FEEDBACK_GOLD=0`，禁用同组成功示范；E2b 使用 `TCRL_FEEDBACK_GOLD=1`，沿用含答案反馈与成功示范配置。两组差值解释为反馈配置整体差异。

D5 的退步主要是参数不匹配。E2a 对这类错误能指出参数不匹配，E2b 可以额外看到标准调用。主指标为同一独立 greedy 评测下 dev_unseen 的严格准确率。逐题报告参数错误修复和新增错误，同时记录实际反馈使用率、采样耗时和峰值显存。

D3 的含答案 SDPO 稳态约 87 秒/步，峰值距离单卡容量仅 641 MiB。每臂训练暂估 45–65 分钟，含启动、验证和回收整轮约 60–85 分钟，按 ¥8.36/h 约 ¥8.36–11.84。先用短程实测检查显存和反馈指标，再确认整轮预算。两臂合计费用可能超过 ¥20。
