# D10 · 隐式换算上的失败驱动课程

2026-11-15 本地准备。D10 比较在 D9 任务上增加同样多的监督更新时，失败驱动课程、均匀生成课程和静态复习的效果。D12 脚本与模型清单保持冻结，封存题留到 D12。D9 的 392 对留出题已有公开给项目组的诊断结果，是本轮开发评测。若选中 D10 checkpoint，D12 才提供本项目原封存集上的一次性结果。

## 候选种子与生成

锁定 D9 数据清单和 `d9-direct-gate-43482.tar.gz` 的 SHA-256，从归档内 `gate/train_probe/samples.jsonl` 按 ID、题型和金标对齐 692 题的八次严格分数。原 588 道调用题有 138 道 8/8、450 道 0–7/8。本地冻结 700 个种子，包括 138 个 8/8 原换算题、366 个训练域直给版本和 196 个分布固定随机抽出的 0–7/8 原换算题（含 65 个 0/8）。基础种子比例 504/700 = 72%。直给种子的八次通过数未知，依据 D9 直给留出题 392/392 的表现作为基础层代理。

| 臂 | 数据策略 | 调用题 | 公共拒答回放 |
|---|---|---:|---:|
| C-S | 从基础层固定均匀重采样，实际为 260 条直给、100 条 8/8 原换算 | 360 | 64 |
| C-U | 全候选池均匀有放回抽种子，E0 生成 1,200 次 | 360 | 64 |
| C-F | 仅 0–7/8 种子，以 8 − pass_count 为权重有放回采样，E0 生成 1,200 次 | 360 | 64 |

两生成臂固定同样的预算、生成提示和校验方式。预定抽样中，C-U 的薄弱种子为 333/1,200，C-F 为 1,200/1,200。带 rate_total、relative_time 或 duration 的隐式换算生成请求分别为 342/1,200、1,122/1,200。这是抽样配额，实际合格产量由上卡后统计。C-U/C-F 隔离种子选择策略，C-S 提供基础题静态复习对照；生成设置与训练开销分别计时。

E0 生成结构化题规格（操作数、表达变体、句式），固定种子的操作数提示在两臂共用。种子决定工具域、操作对及直给／换算模式。确定性求解器根据规格渲染题面并重算完整三调用金标，校验参数类型和训练域八工具 schema。生成词表和题面由模板限定。只使用六个 D9 训练域，按 schema 家族再查与 gate/heldout 零重合。新记录 ID 不算语义新颖性，去掉 lookup ID 后剔除与原训练题及臂内已有题重复的同域、同模式、同参数组合。跨臂重合只记录，保留各策略实际分布。

用 E0 在新生成题上另做一次 n=8（T=1、top-p=1、top-k=-1、512 tokens）。统计校验通过、0/8、1–7/8、8/8 及薄弱换算项数量和比例，混合率同时给出相对有效题和全部生成尝试的分母。0/8 排除，混合题优先，全对题固定种子补足 360。任一臂合格题不足时保存诊断并在训练前停下。

## 训练、终评与 D12 候选

同一原版 E0，直接作答、30 步、有效 batch 32、峰值 lr=3e-5、余弦退火。同一 64 道拒答占各臂 15.09%，每臂 424 条。三组训练完成后，E0 和三臂用 D9 的 greedy 口径（T=0、1024 tokens）评估原 392 对直给/换算题、原 dev_unseen 541 题和 BFCL 1,240 题。留出换算为主指标，另报操作搭配、独立薄弱操作、域级配对净差、外部调用/拒答及 BFCL 分类。C-F 对 C-U 和 C-S 的两项配对 McNemar 检验用 Holm 校正，p 值描述固定题集内的题目差异，按域给出方向用于检查迁移一致性。

D12 候选先按 D9 留出换算正确数排序，同分看原 dev 总分、BFCL 正确数，再按 C-S、C-U、C-F 顺序决胜。结果记录候选及 adapter。D12 清单的实际增补放到 D10 验收后。
